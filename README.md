# tier9studios

Static site for the Tier 9 Studios domain, served via GitHub Pages.

- Pages builds from the `deployment` branch.
- Holds the Terms of Service, `app-ads.txt`, app deeplink files (`.well-known/`), and the Discord redirect.
- Has a support page at `/support/`. Its form posts to the team site's public support route (`https://team.tier9studios.com/api/public/support`).
