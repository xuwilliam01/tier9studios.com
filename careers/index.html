    How we hire

    1. Apply

      Fill out the short form on the role’s page. It only takes a few minutes.

    2. We read it

      Someone on the team reads every application. We don’t use automated tools to score or reject them.

    3. We talk

      If it looks like a good fit, we’ll email you from an @tier9studios.com address to set up interviews.

    4. Offer

      If we’re both excited to work together, we’ll send you an offer.
