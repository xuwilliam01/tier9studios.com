    How we hire

    1. Apply

      Send the form on the role’s page. It takes a few minutes.

    2. We read it

      A person on the team reads every application. No automated tool scores or rejects it.

    3. We talk

      If there’s a fit, we email you from an @tier9studios.com address to set up interviews.

    4. Offer

      If it’s a match on both sides, we make you an offer.
